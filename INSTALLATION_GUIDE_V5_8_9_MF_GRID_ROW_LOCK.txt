AKAR MASALAH YANG DITEMUKAN
Halaman Material & Finishing menggunakan CSS Grid:
  grid-template-rows: auto auto 0 minmax(0, 1fr) auto

Elemen status loading berada pada urutan ketiga. Setelah proses API selesai,
JavaScript mengosongkan teks status. Aturan berikut kemudian aktif:
  .mf-load-status:empty { display: none; }

Karena elemen status dikeluarkan dari layout, CSS Grid melakukan auto-placement ulang:
- workspace berpindah ke row ketiga yang tingginya 0;
- trust strip berpindah ke row keempat dan membesar memenuhi sisa layar.

Gejalanya persis:
- card dan panel detail sempat terlihat;
- setelah sinkronisasi selesai, card dan detail menghilang;
- bagian keunggulan membesar memenuhi ruang kosong.

LANGKAH PEMASANGAN
1. Buka terminal WSL:
   cd ~/projects/nexora-printing-packaging-final-v5.6
   git checkout development
   git pull origin development
   git status

2. Pastikan working tree clean.

3. Backup:
   cd ~/projects
   cp -r nexora-printing-packaging-final-v5.6 \
     nexora-printing-packaging-final-v5.6-backup-before-v5.8.9

4. Ekstrak patch v5.8.9.

5. Salin seluruh isi patch ke:
   \\wsl.localhost\Ubuntu\home\firman\projects\nexora-printing-packaging-final-v5.6

6. Pilih Replace the files in the destination.

7. Jalankan QA:
   cd ~/projects/nexora-printing-packaging-final-v5.6
   npm run qa

8. Target akhir:
   v5.8.9 UI verification PASS

9. Commit dan push:
   git add .
   git commit -m "Lock Material Finishing grid rows after async load"
   git push origin development

10. Tunggu deployment Preview baru berstatus Ready.

11. Uji:
   /material-finishing?type=material&id=ivory-300-gsm
   /material-finishing?type=finishing&id=laminasi-doff

12. Tunggu minimal 10 detik pada masing-masing halaman.
    Pastikan card dan panel detail tidak menghilang setelah API selesai.

13. Hanya setelah Preview PASS, merge ke main.
