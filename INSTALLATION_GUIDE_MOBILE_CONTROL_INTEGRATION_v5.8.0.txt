======================================================================
11. DIAGNOSIS ERROR
======================================================================

PUBLIC_API_NOT_CONFIGURED
- GAS_WEB_APP_URL atau GAS_SHARED_SECRET belum diisi di Vercel.

INVALID_API_SECRET / UNAUTHORIZED
- Shared secret tidak cocok.
- Pastikan menggunakan secret Preview yang sama dengan Apps Script Preview.

BACKEND_TIMEOUT
- Google Apps Script melebihi waktu tunggu.
- Periksa deployment, Spreadsheet, dan Apps Script execution log.

BACKEND_INVALID_JSON
- GAS mengembalikan HTML/error, bukan JSON.
- Pastikan URL yang digunakan adalah URL Web App /exec.

PORTFOLIO_NOT_FOUND
- Slug tidak ada atau portofolio bukan ACTIVE.

Respons sukses tetapi items kosong
- Tidak ada portofolio ACTIVE.
- Ini bukan error integrasi.

Foto material/finishing memakai placeholder
- image_url dan thumbnail_url pada master masih kosong.
